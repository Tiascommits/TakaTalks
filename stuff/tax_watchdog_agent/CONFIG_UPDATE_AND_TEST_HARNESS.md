# Tax Watchdog: Config Update & Test Harness

This document outlines the operational process of updating the TypeScript tax configuration and verifying mathematical accuracy with Vitest.

---

## 1. Step-by-Step Update Procedure

When a new Finance Act is enacted for Assessment Year $YYYY-YY$:

1. **Create New Rules Config**:
   Duplicate the previous year's file:
   `cp web/src/config/tax-rules-2025-26.ts web/src/config/tax-rules-YYYY-YY.ts`

2. **Apply Verified Changes**:
   Modify values according to the gazetted SRO / Finance Act. Ensure all constants remain strongly typed:

   ```typescript
   export const TAX_RULES_YYYY_YY: TaxRulesConfig = {
     assessmentYear: "2026-27",
     incomeYear: "2025-26",
     effectiveDate: "2026-07-01",
     gazetteReference: "Finance Act 2026 (Act No. XX of 2026)",
     taxFreeLimits: {
       general: 400000,
       femaleAndSenior65Plus: 450000,
       disabled: 525000,
       gazettedFreedomFighters: 550000,
       thirdGender: 525000,
     },
     disabledDependentCeilingBonus: 50000,
     standardSalaryExemption: {
       fractionOfGross: 1 / 3,
       maximumCap: 550000,
     },
     incomeSlabs: [
       { limit: 100000, rate: 0.05 },
       { limit: 400000, rate: 0.10 },
       { limit: 500000, rate: 0.15 },
       { limit: 500000, rate: 0.20 },
       { limit: 2000000, rate: 0.25 },
       { limit: null, rate: 0.30 }, // remainder taxed at 30%
     ],
     rebateRules: {
       taxableIncomePercentage: 0.03,
       eligibleInvestmentPercentage: 0.10,
       maximumRebateCap: 750000,
     },
     // ...
   };
   ```

## 2. Test Suite Expansion in Vitest

Before opening a PR, the agent MUST expand the unit test suite in `web/src/lib/tax/calculate.test.ts` to test every new rule boundary:

### Test Scenarios Generated by the Agent:
1. **Tax-Free Boundary Edge Cases**:
   - Gross taxable income exactly at the limit (e.g. ৳3,99,999 vs ৳4,00,000 vs ৳4,00,001). Assert payable tax transitions smoothly from 0 to positive.
2. **Standard Salary Exemption Upper Cap**:
   - High earner with ৳30,00,000 gross salary ($1/3 = 10,00,000$, capped at the new ৳5,50,000). Assert exemption does not exceed the cap.
3. **Rebate Ceiling Clamping**:
   - Ultra-high investment of ৳1,00,00,000. Assert rebate does not exceed ৳7,50,000 cap or 3% taxable income limit.
4. **Minimum Tax Enforcement**:
   - Taxpayer whose calculated slab tax minus rebate equals ৳800. If located in Dhaka City Corporation, assert final payable clamps to minimum tax (৳5,000, or ৳1,000 if first-time filer).
5. **Adversarial & Fuzz Testing**:
   - Negative income, decimals, huge numbers ($10^{14}$). Verify the engine never produces `NaN`, `Infinity`, or negative payable tax.

## 3. Pull Request Template & Check

The agent generates a Git branch `feat/tax-rules-YYYY-YY` and opens a PR with:
- Link to the gazetted Bangladesh Gazette PDF.
- Diff of the config file.
- Vitest results: `npm test` passing with 100% coverage across rules.
- Confirmation that no UI or calculation logic files were broken.
